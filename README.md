# FUTURE_FS_02
# Apex LeadFlow CRM | Future Interns Task 2

## Project Overview
This project is my submission for **Task 2** of the Full Stack Web Development Internship at Future Interns.

The task required building a **Client Lead Management System (Mini CRM)** to help businesses manage customer leads efficiently.

This CRM was built for **Apex Fitness Club**, integrating with Task 3's business website workflow.

---

## Problem
Businesses often struggle to manage incoming customer leads from multiple channels such as:
- Website
- WhatsApp
- Instagram
- Referrals

Without a proper system, lead tracking becomes inefficient.

---

## Solution
I built **Apex LeadFlow CRM**, a responsive dashboard that allows admins to:

- Add leads
- Track lead status
- Update notes
- Filter leads
- Search leads
- Export lead data

---

## Features
- Admin login system (demo)
- Add new leads
- Lead database dashboard
- Status tracking
- Search and filters
- Delete leads
- CSV export
- Dark mode
- localStorage persistence
- Responsive UI
